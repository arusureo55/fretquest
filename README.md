# FretQuest（PWA版）

ホーム画面に追加して、アプリとしてマイク判定を使うためのファイル一式です。

## ファイル

| ファイル | 役割 |
| --- | --- |
| index.html | アプリ本体 |
| manifest.webmanifest | アプリ名、アイコン、全画面表示の設定 |
| sw.js | オフラインでも起動できるようにするService Worker |
| icons/ | アプリアイコン（192px、512px、Android用のマスク対応、iPhone用） |

## GitHub Pagesで公開する手順

マイクはHTTPSで公開したページでしか使えません。ファイルを直接開いた場合は使えないため、必ず公開してください。

1. GitHubで新しいリポジトリを作る（例：fretquest）
2. このフォルダの中身をすべてリポジトリの直下にアップロードする（index.html が直下に来るようにする）
3. リポジトリの Settings → Pages を開き、Source を「Deploy from a branch」、Branch を「main」「/ (root)」にして保存する
4. 数分後に表示されるURL（例：https://ユーザー名.github.io/fretquest/）を開く

Cloudflare PagesやNetlifyでも、このフォルダをそのままアップロードすれば同じように動きます。

## スマートフォンへのインストール

- **iPhone**：Safariで公開URLを開き、共有ボタン →「ホーム画面に追加」
- **Android**：Chromeで公開URLを開き、メニュー →「アプリをインストール」（または「ホーム画面に追加」）

初回にマイクの許可を求められたら「許可」を選んでください。iPhoneでは、起動のたびに許可を聞かれることがあります。

## 使い始めるとき

- 伴奏の音を拾わないよう、イヤホンでのプレイをおすすめします
- 最初に遅延キャリブレーションを行ってください（設定からいつでも測り直せます）
- 音を聞く方法（有線、スピーカー、Bluetooth、オーディオIF）を変えたら、測り直してください

## アンプなしで弾くとき

アンプにつながずに弾くと、ギターの音が小さくマイクで聞き取りにくくなります。最初に「音の聞き取り」を合わせてください（初回案内でマイクを許可したあとに表示されます。あとからは 設定 →「音の聞き取り」→「合わせる」）。

- 周りの音を1.5秒測り、開放6弦を4回弾くと、音の大きさから自動で設定します
- 音が小さい場合は「アンプなし」の設定になり、ギターの音域（70Hz〜4kHz）だけを聞き取って入力を増幅し、検出の基準を下げます
- アンプやオーディオIFから鳴らしている場合は「アンプあり」のままで、これまでと同じ判定になります
- 合わせたあと「試し弾き」で、弾いた音が聞き取れるかを確かめられます
- スマホはギターから20〜30cm以内に置き、マイクを弦に向けてください。伴奏はイヤホンで聞いてください

設定画面の「ギターの音」「入力の増幅」「発音を検出する大きさ」で、手動でも変えられます。アンプにつないだ大きな音で「アンプなし」の設定を使うと、1回の音を2回と数えることがあるので、つなぎ方を変えたら合わせ直してください。

## claude.ai版との違い

- 進捗は端末内にだけ保存されます。アカウントへの同期と、端末をまたいだ引き継ぎはできません
- リーグ（ほかの人との順位）と判定の報告の送信は使えません（報告は端末内に記録されます）
- これらは、仕様書「3. バックエンド」のサーバーを用意した段階で戻す想定です

## 更新するとき

index.html を差し替えたら、sw.js の先頭にある `CACHE = 'fretquest-v1'` の番号を上げてください（v2、v3…）。インストール済みの端末にも新しい版が届くようになります。
